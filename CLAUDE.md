# CLAUDE.md — Biota

Рабочая спецификация для Claude Code. Прочитай целиком перед изменениями: энкодеры
(Sketch JS, Figma JS), Python-декодер и десктоп-приложение (Tauri, TS) реализуют один
и тот же формат **четырьмя независимыми кодовыми базами**. Любое расхождение в
формате/константах ломает совместимость молча.

## Что это
Biota кодирует текст в углы поворота шестиугольных тайлов (honeycomb-сетка),
6 углов = шестеричные цифры. Текст шифруется секретом, защищается Рида–Соломоном,
рисуется в Sketch/Figma, экспортируется в PNG и восстанавливается Python-декодером
из пикселей. Подробный обзор — в `README.md`.

## Карта файлов
- `encoder/sketch/encoder.js` — Sketch (CocoaScript/ES2020), запуск через Run Script. Диалог `NSAlert` (3 поля) + крипто + RS + построение сетки.
- `encoder/figma/{manifest.json,code.js,ui.html}` — плагин Figma. `ui.html` (iframe, есть WebCrypto) делает крипто+RS+цифры; `code.js` (sandbox) строит инстансы. Связь через `postMessage`.
- `decoder/decode.py` — Python-декодер (CLI). Автодетект сетки + классификация + RS + расшифровка. CLI: argv или интерактив.
- `app/` — десктоп-приложение (Tauri 2, vanilla TS). `src/biota/*` — полный порт энкодера И декодера на TS (4-я кодовая база); `src-tauri` — тонкий Rust (команда `save_file` + плагин диалога). Тесты: `app/tests/run.ts` (`npm test`) сверяют ядро с Python и сэмплом. Подробности — `app/README.md`.
- `templates/tpl_0..5.png` — эталоны: тайл в поворотах `0..300°`, @1x, белые арки на прозрачном фоне. (Скопированы в `app/src/assets/templates/` — при регенерации обновляй обе копии.)
- `tools/sketch-export-templates.js` — регенерация эталонов из Sketch.
- `samples/sample_encrypted.png` — демо: text `"Welcome to Biota! Secret message hidden in tile rotations."`, secret `biota-demo`, COLS=10.

## Формат данных (точная спецификация)
Кодирование `текст → PNG`, по слоям:

1. **UTF-8**: `plain = utf8(text)` (байты).
2. **Шифрование** (`encrypt`):
   - `salt` = 8 байт случайных (Figma: `crypto.getRandomValues`; Sketch: `Math.random`).
   - `key = SHA256^ITER(secret ∥ salt)`: `k = SHA256(secretBytes ∥ salt)`, затем `ITER` раз `k = SHA256(k ∥ secretBytes)`.
   - keystream (CTR): конкатенация блоков `SHA256(key ∥ counter32be)`, counter с 0.
   - `ct = plain XOR keystream`.
   - `mac = SHA256(key ∥ ct)[:4]` (4 байта).
   - `payload = [ver=1 (1B)] [N (2B, big-endian = len(plain))] [salt (8B)] [mac (4B)] [ct (N B)]`. Заголовок = 15 байт.
3. **Reed–Solomon** (GF(256), `prim=0x11d`, `generator=2`, `fcr=0`):
   - `body`: payload режется на чанки по `KBLK` байт; каждый → `rsEncode(chunk, NSYM)` (добавляет `NSYM` паритета).
   - `hdr = rsEncode([bodyLen>>8, bodyLen&255], HDR_NSYM=4)` → 6 байт.
   - `frame = hdr ∥ body`.
4. **Шестеричные цифры**: каждый байт `b` → 4 цифры, старший разряд первым:
   `[floor(b/216)%6, floor(b/36)%6, floor(b/6)%6, b%6]`. (Валидный байт даёт первую цифру ∈{0,1}.)
5. **Добивка**: цифры дополняются нулями до кратности `COLS` (чтобы последний ряд был полным).
6. **Раскладка**: тайл размером `W` (ширина символа/компонента). `dx=round(W·√3/2)`, `dy=W·0.75`, `off=dx/2`. Для индекса `i`: `r=floor(i/COLS)`, `c=i%COLS`; **чётные ряды (`r%2==0`) сдвинуты на `+off`**. Поворот тайла = `цифра·60°`. Порядок чтения — построчно (сверху-вниз, слева-направо).
7. **Экспорт** группы в PNG.

Декодирование — строго обратное (см. ниже).

## Инварианты (ОБЯЗАНЫ совпадать во всех четырёх кодовых базах)
- `ITER = 20000`, `NSYM = 8`, `KBLK = 223`, заголовочный RS `nsym = 4`.
- Формат payload `[ver|N|salt|mac|ct]`, размеры 1/2/8/4/N, `N` big-endian.
- KDF/keystream/MAC ровно как выше (порядок конкатенаций важен).
- RS-параметры: `prim=0x11d`, `generator=2` (α=2), `fcr=0`. Подтверждено: наш JS-`rsEncode` == Python-`reedsolo` байт-в-байт.
- Маппинг цифра↔угол: `угол = цифра·60`, старший разряд первым, 4 цифры/байт.
- Геометрия: `DX0=294`, `DY0=255`, `off=dx/2`, чётные ряды сдвинуты; reference `W0=340`.
- Порядок чтения построчный; чётные (верхний = ряд 0) ряды со сдвигом.
При смене любой константы правь **все четыре** базы (Sketch, Figma, Python, `app/src/biota`) сразу.

## Декодер: как работает (`decoder/decode.py`)
1. `composite_lum`: PNG(RGBA) на чёрный фон → арки ≈255, фон 0; порог 128 → бинарь.
2. `estimate_scale`: масштаб из периода решётки по **осевой автокорреляции** (берётся ось с более уверенным пиком: горизонталь→`dx`, вертикаль→`2·dy`). Устойчиво к малому числу рядов/столбцов.
3. Геометрия **жёсткая**: `dx=DX0·scale`, `dy=DY0·scale`, `off=dx/2` (НЕ мерить по пикам — иначе дрейф на больших сетках).
4. Центры тайлов: matched-filter с **rotation-invariant** ядром (среднее 6 эталонов) → пики; origin (`ax`,`ay`) — по медиане остатков относительно фиксированного шага.
5. Снап пиков в ячейки `(r,c)`: сперва отсекаются разреженные граничные **строки** (поля картинки рождают ложные пики, которые иначе сдвинули бы индексы строк и инвертировали чётность сдвига), чётность привязывается к верхней плотной строке, затем отбор плотного блока **столбцов** (дропает спурьёзные), достройка пропусков по идеальной решётке. Тот же row-trim есть в TS-декодере `app/` — держи синхронно.
6. `classify`: NCC центрального диска (радиус `R0·scale`, внутри зоны без перекрытий) против 6 эталонов → цифра `0..5`.
7. Цифры → байты (`&0xFF`; испорченный тайл = ошибочный байт для RS) → `rs_decode_frame` (исправление) → `decrypt_payload` (расшифровка + проверка MAC).

## Команды
```bash
pip install -r decoder/requirements.txt
python3 decoder/decode.py <png> "<secret>"     # прямой режим
python3 decoder/decode.py                       # интерактив (file picker + getpass)
HEX_TPL_DIR=/path/to/tpl python3 decoder/decode.py <png> "<secret>"
# самопроверка на демо:
python3 decoder/decode.py samples/sample_encrypted.png biota-demo   # -> 'Welcome to Biota! ...'
```
Регенерация эталонов: `tools/sketch-export-templates.js` (Sketch) либо из Figma
(см. ниже) — эталоны ДОЛЖНЫ соответствовать ассету и инструменту кодирования.

## Подводные камни
- **Эталоны = тот же ассет и тот же инструмент.** Эталоны в `templates/` сделаны из Sketch-символа (`symbolId E6D5726C-5718-45B8-A51E-D346D9857967`, асимметричный гекс, `W=340`, белые арки на прозрачном). Для Figma-ассета регенерируй из Figma.
- **Симметрия узора.** Тайл должен быть полностью асимметричным (нет 2-/3-/6-кратной симметрии узора), иначе часть из 6 классов сольётся. Текущий ассет это выполняет (точность 1.0 на сотнях тайлов).
- **Знак поворота (Figma).** В `code.js` есть `DIRSIGN` (по умолчанию `-1`). 6 углов замкнуты относительно знака → флип лишь переставляет цифры `d→(6−d)%6`. Если эталоны регенерированы тем же инструментом, что и кодирование, знак не важен. Симптом неверного знака при переиспользовании Sketch-эталонов: текст «переставлен» → поставь `+1`.
- **Минимум 2 ряда** для автодетекта масштаба (нужна периодичность хотя бы по одной оси).
- **Прямой экспорт** (оси не повёрнуты, без фото/сильного JPEG). Для съёмки нужен доп. этап выравнивания (гомография) — пока нет.
- **Лавинность шифра.** Один неисправленный тайл рушит расшифровку целиком и валит MAC. На чистых экспортах декод 100%; устойчивость к ошибкам даёт RS (см. NSYM).
- **Fonт/фон тайла.** Декодер ждёт светлые арки на тёмном/прозрачном (порог 128). Другая палитра — поправь `composite_lum`/порог.

## Известные ограничения / Roadmap
- KDF самодельный и дешёвый (см. README «Безопасность»). Усиление: вынести шифрование в Python (`scrypt`/`argon2` + AES-GCM), тогда Sketch/Figma рисуют готовый payload. Это изменит формат payload и потребует синхронной правки энкодеров.
- ECC только error-correction. Можно добавить **erasure**: цифровые группы со значением >255 точно ошибочны → пометить как стирания (RS правит вдвое больше стираний, чем ошибок).
- Figma: добавить режим «Export templates» (6 повёрнутых инстансов → PNG-байты на скачивание из UI).
- Упаковать Sketch-энкодер в `.sketchplugin` с пунктом меню.
- Перенести `rsEncode`/SHA-256/крипто в общий «source of truth», из которого генерятся обе JS-копии (сейчас дублируются — следи за синхронностью).
