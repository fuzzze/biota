# Biota

Стеганография на поворотах. Biota прячет произвольный текст в **углах поворота
цепочки шестиугольных тайлов** (honeycomb-сетка). Текст шифруется секретом,
защищается кодом Рида–Соломона и кодируется в **шестеричной системе** (6 углов
`0/60/120/180/240/300°` = цифры `0..5`). Закодированную сетку рисуют в **Sketch**
или **Figma** и экспортируют в PNG; **Python-декодер** восстанавливает текст
прямо из пикселей картинки — без какой-либо метаинформации.

Ключевая идея: правильный шестиугольник симметричен, поэтому угол читается не по
контуру, а по **асимметричному узору внутри тайла**. Тайл при повороте на 60°
выглядит иначе — это и несёт данные.

```
текст
  → UTF-8
  → ШИФР(secret):  [ver|N|salt|mac|ciphertext]        (SHA-256 KDF + CTR + MAC)
  → RS(GF256):     [len-header+RS] + [блоки данных +паритет]   (исправление ошибок)
  → 6-ричные цифры (4 цифры на байт)
  → honeycomb-сетка тайлов, угол = цифра·60°
  → PNG

PNG → автодетект сетки → классификация поворотов по 6 эталонам
    → цифры → байты → RS-исправление → расшифровка+проверка MAC → текст
```

## Быстрый старт

### Декодирование (Python)
```bash
cd Biota
pip install -r decoder/requirements.txt          # numpy scipy pillow reedsolo

# демо-семпл: text "Welcome to Biota! ..." , secret "biota-demo"
python3 decoder/decode.py samples/sample_encrypted.png biota-demo

# интерактивно (нативный выбор файла macOS + скрытый пароль)
python3 decoder/decode.py
```
Декодер сам определяет масштаб экспорта, число столбцов `COLS`, origin и размеры
сетки. Эталоны ищутся в `$HEX_TPL_DIR`, затем `./templates`, `../templates`.

### Кодирование (Sketch)
1. Выдели гекс-символ (или группу с его инстансом).
2. Sketch → Plugins → Run Script… (включи Developer mode) → вставь
   `encoder/sketch/encoder.js`.
3. Введи Text / Tiles per row / Secret → появится группа `encrypted` → экспортируй в PNG.

### Кодирование (Figma)
1. Plugins → Development → Import plugin from manifest → `encoder/figma/manifest.json`.
2. Выдели компонент гекс-тайла (или его инстанс) → запусти плагин → введи данные.
3. Экспортируй группу `encrypted` в PNG.

> Эталоны `tpl_*.png` должны соответствовать тому же ассету и инструменту, что
> и при кодировании. Для Figma-ассета регенерируй эталоны из Figma (см. CLAUDE.md).

## Свойства

- **Произвольная длина и неизвестный `COLS`** — декодер определяет всё из картинки.
- **Шифрование секретом** — без него текст не извлечь; неверный секрет ловится MAC.
- **ECC (Рида–Соломона)** — переживает ошибки распознавания тайлов
  (по умолчанию до ~4 ошибочных тайлов на каждые 223 байта данных).
- **Любой текст** — UTF-8 (латиница, кириллица, эмодзи).
- **Любой масштаб экспорта** — @1x/@2x/нецелый, определяется автоматически.

## Безопасность (кратко)

Стойкость определяется **энтропией секрета**, а не алгоритмом. KDF самодельный и
дешёвый (20000 итераций SHA-256 ≈ +14 бит к энтропии), атака полностью офлайн
(`salt`,`mac`,`ciphertext` лежат в PNG). На GPU ≈ 10⁶ попыток/с.

| Секрет | Примерное время взлома |
|---|---|
| словарное слово / 8 строчных | секунды … день |
| 4 diceware-слова (~2⁵²) | один GPU ~60 лет, ферма ~недели, гос ~минуты-часы |
| 6 diceware-слов / 12+ случайных символов (~2⁷⁷⁺) | практически недостижимо |

Вывод: используй **длинную парольную фразу**. Для серьёзной защиты вынеси
шифрование в настоящий KDF (scrypt/argon2) + AES-GCM вне Sketch/Figma — см.
раздел «Roadmap» в CLAUDE.md.

## Лицензия / статус

Внутренний прототип. Самодельная крипто-конструкция — не для защиты реально
ценных секретов без замены KDF/шифра на проверенные библиотеки.
