# Biota — десктопное приложение (Tauri 2)

Кроссплатформенное (macOS/Windows) приложение для кодирования/декодирования Biota.
Тёмная минималистичная тема, шрифт JetBrains Mono (забандлен офлайн). Две вкладки:

- **Зашифровать** — ввод текста, выбор пропорций картинки (вертикальная/квадратная/
  горизонтальная, число столбцов считается из длины сообщения), пароль с переключателем
  видимости, предпросмотр узора, сохранение PNG через нативный диалог.
- **Расшифровать** — загрузка PNG (drag-and-drop или выбор файла), пароль, вывод текста.

Тайлы (`tpl_0..5.png`) встроены в приложение — пользователь их не вводит.

## Архитектура

Вся криптография, Reed–Solomon и обработка изображений — **на TypeScript во фронтенде**
(`src/biota/`), это четвёртая независимая реализация формата Biota (порт энкодеров из
`encoder/figma/ui.html` и декодера из `decoder/decode.py`). Rust-бэкенд тонкий: только
нативный диалог сохранения (`save_file`).

```
src/biota/
  sha256.ts     SHA-256 + UTF-8 (порт из ui.html)
  crypto.ts     KDF + CTR + MAC: encrypt / decryptPayload
  rs.ts         Reed-Solomon: encode (порт) + decode (новый, как reedsolo)
  digits.ts     байты <-> шестеричные цифры
  fft.ts        FFT (1D/2D) для декодера
  imaging.ts    яркость, ресэмплинг, маска-диск, max-фильтр
  decode.ts     PNG -> текст (порт decode.py: масштаб, matched-filter, NCC, RS, расшифровка)
  layout.ts     выбор COLS под пропорции + раскладка honeycomb
  render.ts     общий рендер сетки (используется и тестом)
  templates.ts  загрузка встроенных эталонов
  constants.ts  геометрия (DX0/DY0/R0) + RENDER_SCALE
```

> Инварианты формата (`ITER`, `NSYM`, `KBLK`, payload-формат, геометрия) обязаны
> совпадать с тремя другими кодовыми базами — см. корневой `CLAUDE.md`.

## Разработка

```bash
npm install
npm run tauri dev      # запуск с hot-reload
npm test               # Node-тесты ядра (RS, декод сэмпла, roundtrip, кросс-тул с Python)
npm run tauri build    # сборка .app + .dmg (macOS) / .exe + установщик (Windows)
```

Требуется Rust ≥ 1.85 (зависимости Tauri используют `edition2024`).

## Сборка / распространение

`npm run tauri build` кладёт артефакты в
`src-tauri/target/release/bundle/`:

- macOS: `macos/Biota.app` (запуск без установки — перетащить и открыть) и `dmg/Biota_*.dmg`.
  Сборка не подписана: при первом запуске — правый клик → «Открыть» (обойти Gatekeeper).
- Windows: собирается на Windows-машине или через CI (Tauri не кросс-компилирует с macOS).

## Известные ограничения

- Декодирование идёт в основном потоке: на больших изображениях UI замирает на 1–3 с
  (показывается статус «Расшифровка…»). Кандидат на вынос в Web Worker.
- Декодер ждёт прямой экспорт (без фото/сильного JPEG), как и `decoder/decode.py`.
